# TomiLite v2.0.4

**Since v2.0.3** — Bug fixes, documentation overhaul, and open-source polish.

---

## 🐛 Fixes

- **Task menu crash**: fixed `useRef is not defined` error when opening the task menu (missing React import)
- **Editor toolbar restored**: Task / Email / Note / Report editors' Markdown toolbar buttons (Bold, Italic, Headings, Table, etc.) now render with proper styling again — the Milkdown editor styles were missing from the stylesheet
- **Semantic badge colors**: task priority/type badges now use design-token CSS variables (`--red` / `--amber` / `--blue` / `--purple` / `--muted`) instead of hardcoded hex values
- **Drag performance**: task drag-to-status updates the ghost element via refs with zero React re-renders per mousemove; status updates are DB-first — the UI only changes after the database update succeeds (failure shows a toast, UI stays unchanged)

## 📖 Documentation

- **Reorganized for open source**: removed internal engineering docs (refactor plans, bugfix logs, i18n checklists) and renamed the remaining docs semantically — `architecture.md`, `mcp-client.md`, `email-ai.md`, `tasks-panel.md`
- **Docs aligned with code**: all documentation audited against the actual v2.0.4 implementation (panel structure, hooks, i18n architecture, OTA via GitHub Releases, MCP client design)
- **Source comments**: `App.tsx` and `main.tsx` now carry English section comments explaining the thin-shell architecture and entry-point bootstrapping
- **README**: per-document links, afdian support link, and setup guide
