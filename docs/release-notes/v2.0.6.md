# TomiLite v2.0.6

**Since v2.0.5** — Hotfix.

## 🐛 Fixes

- **Shortcuts disappearing after OTA update**: the NSIS custom-init script deleted the current product shortcuts on every install/update, and update mode does not recreate them. The installer now only removes legacy TomatoLite shortcuts — Start Menu and Desktop shortcuts survive updates.

> **Already lost your shortcuts after updating to 2.0.5?** Reinstall v2.0.6 (run the installer manually) — it recreates Start Menu and Desktop shortcuts. Alternatively launch `TomiLite.exe` from the install folder (`%LOCALAPPDATA%\Programs\TomiLite\`) and pin it again.
