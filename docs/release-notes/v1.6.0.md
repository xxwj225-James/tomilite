# TomiLite v2.0.1

**~200 commits since v1.0.2** — intelligent email triage, daily reporting, i18n, cross-provider LLM support, and UI polish.

---

## 📧 Intelligent Email

- **AI-powered 4-category classification**: Urgent (Cat 1), Action Required (Cat 2), Notifications (Cat 3), Other (Cat 4)
- **LLM sub-grouping per category**: fixed groupKeys with centralized i18n labels — no free-form AI text in UI
  - Cat 1: Incidents / Escalations / Other
  - Cat 2: Reviews / Tasks / Questions / Other
  - Cat 3: Security / System / Reports / Other
  - Cat 4: Promotions / Digests / Other
- **Tree-line mindmap visualization**: category cards → sub-group cards → paginated email tables with SVG connectors
- **AI reply drafts**: auto-generated for Cat 1/2, manual reply for Cat 3/4
- **Editable To/CC/Subject**: user-editable before sending; CC support in backend
- **Email-to-task linking**: AI-generated task title + description from email content
- **Batch operations**: multi-select dismiss with parallel API calls
- **Pagination**: 15 emails per page in sub-group tables

## 📋 Daily Reports

- **Morning brief**: priority-grouped task table with encouragement and focus suggestions
- **Evening report**: structured summary with priority tables, completed items, code activity, and tomorrow's focus
- **Rich visual styling**: gradient section headers, card-style blockquotes, branded table headers
- **Export**: one-click Excel (.xlsx), Word (.docx), HTML (.html) — styled, self-contained output

## 📝 Notes & Knowledge Base

- **Export**: Excel / Word / HTML / Markdown — multi-note selection exports each note as a separate file
- **Pagination**: 20 notes/reports per page with prev/next controls

## 🎨 UI & Visual Design

- **Health Score dashboard**: 4-dimension radial score ring, colored progress bars, 7-day trend sparkline
- **Motto banner**: daily AI-personalized encouragement on the home page
- **Welcome guide**: per-item configuration detection with ✅ indicators, dismissible permanently
- **Panel bottom spacing**: consistent 80–160px breathing room across all panel scroll containers
- **Table borders**: full cell borders in both preview and editor modes

### Design System

All visual elements use **CSS custom properties** (`var(--brand)`, `var(--surface)`, `var(--edge)`, etc.) — automatically adapting across Pipeline / Hub / Canvas / Quantum themes. No hardcoded colors.

## 🌐 Full i18n Support

- **Chinese / Japanese / English** across all UI text
- **Centralized key-based architecture** (`i18n.ts`) — all inline ternaries migrated
- **Backend i18n**: server-generated content uses the same dictionary pattern
- **Email sub-group labels**: `groupKey` → i18n dictionary, language-independent

## 🔌 MCP & Agent

- **Claude Code integration**: MCP long-polling with synchronous approve/deny
- **New MCP tools**: `get_report`, `list_notes`
- **Hallucination guard**: structural pattern detection prevents fake tool confirmations
- **Dedup simplified**: exact title match in DB — no LLM call, instant, never breaks
- **translate_report**: `targetLanguage` required parameter forces LLM to confirm language before translating

## 🤖 LLM Support

- **Qwen 3.7 / 3.8**: `enable_thinking: false` for JSON/tool calls, native `enable_search`, thinking injection for main agent loop
- **Kimi (Moonshot)**: `thinking: { type: 'disabled' }` for classification/dedup/guard calls
- **DeepSeek**: 1M context, `thinking: disabled` for JSON output

## ⚡ Performance

- **Optimistic delete**: Notes and Reports removed from UI instantly — no extra API round-trip
- **Dedup zero-cost**: exact title match without LLM overhead

## 🔧 Infrastructure

- **Note export in wiki router**: moved from `report.ts` to `wiki.ts` for correct domain separation
- **Windows Store compliance**: gated auto-updater, hardened API auth, CSP headers
- **OTA updates**: user-controlled install with progress tracking
- **Data migration**: auto-migration from old `~/.tomilite` to `userData` directory
