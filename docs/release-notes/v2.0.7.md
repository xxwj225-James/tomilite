# TomiLite v2.0.7

**Since v2.0.6** — Image paste in editors.

## 🖼 New

- **Paste images into editors**: Task description, Note, and Report editors now accept pasted images (screenshots, copied images) — Ctrl+V inserts the image inline (stored as data-URL in the document). Multiple images per paste supported.
