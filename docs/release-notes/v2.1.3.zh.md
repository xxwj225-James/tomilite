# TomiLite v2.1.3

**自 v2.1.2 起** —— 中文检索真正可用了：全文索引换成 trigram 分词器重建，语义检索改由本机模型完成。聊天会话现在会自动沉淀成笔记，会议决议也变成可带理由的行记录，并新增跟进邮件草稿与两条提醒。

## ✨ 新功能

- **🔍 检索重建** —— 中文全文检索此前是静默返回空的。索引用 `tokenize='porter unicode61'` 建立，它会把**一整串**汉字/假名当成**一个** token，所以中文查询只有恰好等于某个被索引的整串时才命中：`迁移`、`数据库` 命中 0 条，而 `迁移决定` 命中 1 条。
  - 索引还在**每次启动**时重复灌入 —— 1,616 条源数据膨胀成 498,107 条索引行，1.43 GB，占整个数据库的 95%。改用 `trigram` 重建后搜索恢复，同时收回这部分空间：现在索引恰好每条源数据一行。
  - 重建是自愈的：在 API 开始监听之前、单个事务内完成；任何前置条件不满足都只在下次启动重试，而不会被记成「已完成」。每次启动还会把索引行数与源表对比一次，让当初造成膨胀的无条件重灌不能再悄悄回来。
  - 查询在进入索引前会被加引号，`id-1` 与 `a"b` 现在是正常检索，不再抛语法错。`type` 列不再是可检索文本。
  - 释放空间的动作在窗口打开**两分钟之后**才执行，绝不发生在启动过程中。
- **🧠 语义检索，在你自己的机器上** —— 笔记与报告可以按含义匹配，而不只是按关键词，靠的是在进程内运行的本机 **multilingual-e5-small** 模型（q8，384 维）。因为是多语言模型，中文提问可以命中英文标题的笔记。
  - 模型**不在安装包里**，首次使用时下载（约 135 MB，带校验），在它到位之前检索降级为关键词 —— 不报错，也不会卡住任何一轮对话。
  - 原先的远端 embedding 路径已删除。它对 DeepSeek（默认）、Anthropic 和托管网关都是死路；对 OpenAI 和 Qwen 则有害：它们会往同一个被 384 维查询读取的列里写入 1536 或 1024 维向量，长度不匹配会静默地把这些行永远排在最后。
  - 向量现在记录产生它的模型，因此来自其他模型的向量会被当作未命中并强制重算，而不再是宽度错误的数组。写入集中到队列 + 触发器上，所以**每一条**笔记与报告的写入路径都会重新向量化（包括以后新加的路径），编辑也不会留下过期向量。
  - Agent 的 `search_notes` 现在是真正的混合检索：关键词（BM25）与语义结果用 RRF 融合。结果带笔记 id，Agent 能打开自己刚找到的东西。
- **📝 会留下笔记的聊天** —— 长对话过去会随会话一起消失。现在，会话静默 3 分钟且新增消息 ≥6 条后，模型会把这段窗口折叠成**每个会话一篇滚动笔记**，出现在「笔记」面板：决议及其理由、长期偏好、项目事实、约定、未结的线头。闲聊、复述以及笔记里已有的内容会被丢掉。
  - 笔记是重写而非追加，因此一个会话的笔记始终是摘要，不会变成流水账。它和普通笔记一样被索引，立刻可搜。
  - 水位线只在成功写入后推进，因此崩溃或错误响应会重放该窗口，而不是丢掉它。
  - 它用你配置的 LLM 在后台运行，所以有刹车：每个会话 30 分钟退避；网关报告额度耗尽或账号被停时整体暂停 6 小时；也可以用 `distill.enabled` 设置彻底关闭。Token 与费用按次记录，上报遥测的**只有聚合计数**，绝不含笔记正文或标题。
- **🗂 会议决议变成行记录** —— 决议原本是一个 JSON 字符串、以只读列表呈现，既不能带理由、日期，也不能对单条做任何操作。现在它们是行记录，已有会议会自动迁移。
  - 只有在转写中**确实提到**时才会记录理由 —— **绝不推断**。
  - 跟进邮件草稿只用摘要、决议和行动项撰写，绝不读转写全文，所以它的成本不随会议时长增长。
  - 两条提醒通过常规 Windows 通知发出：行动项明天到期时，以及会议已过 N 天但仍有未处理行动项时。两条都按行去重，重启不会重复通知。邮件仍**只生成草稿**，绝不自动发送。

## 🔒 隐私

TomiLite 依旧本地优先 —— 任务、笔记、邮件、报告、聊天、会议录音与转写、API key、git 数据以及**检索索引**都存在你自己 `~/.tomilite/` 下的 SQLite 里。

检索用的 embedding 由**你设备上**的模型在你的应用内计算；笔记与报告正文不会被发到任何地方来建立索引。检索发出的网络请求只有一次性的模型下载和你自己配置的 LLM 调用。聊天沉淀是唯一会自行把对话文本发给你 LLM 服务商的功能 —— 上面已披露，计费与任何其他调用相同，也可以关闭。

## ⚠️ 说明

- **安装包增大约 29 MB**（157 MiB → 186 MiB）。本机 embedding 需要 ONNX 运行时，它随应用一起分发；模型本身不随包。
- **两个字的中文查询**（如 `迁移`）仍无法由 trigram 索引服务 —— 这是结构性的，不是 bug。现在会退回子串匹配，所以它会返回结果而不是空。更长的查询走快速索引。
- `npm audit`：**9 high → 0**。

## 🐛 修复

- **一轮里创建的多个任务现在是一张表。** 让 Agent 创建 4 个任务，此前会渲染 4 张卡片，而其中只有最后一张的打开/编辑/删除按钮可用。多个任务现在渲染成表格 —— 每行一个任务，随创建过程流式出现，每行有自己的操作；单个任务仍保持熟悉的卡片形态。
- **任务卡片不再显示空白描述或缺失的故事点** —— 两者此前都读自一个恒为空的字段，而不是工具返回值。
- **`brave_search` 在无法工作时不再提供。** 它的 key 读自一个没有设置项的环境变量，所以在每个已发布版本里它每次调用都失败 —— 而它的描述却让模型「优先」用它。现在无 key 时不再暴露该工具，`web_search` 被描述为主工具并自行发起 HTTP 请求（因此在托管网关上同样可用），另外移除了那条让 Qwen 用户彻底没有网页搜索的规则。
- **Markdown 工具栏命令作用于你点击的那个编辑器。** H1/H2/H3、列表和引用此前打到模块级单例上，而 Milkdown 每次加载编辑器都会重新绑定它，导致除最后一个挂载的编辑器外，它们在任何编辑器里都静默无效。
