# TomiLite v1.0.3 Release Notes

> Changes since v1.0.2

---

## 🚀 Major New Features

### 📧 AI Email Panel (All New)
- **Dedicated Email Panel** — Email is now fully separated from the Tasks panel with its own menu entry (Home → Email)
- **4-Category AI Classification** — 🔴 Urgent / 🟡 Reply Today / 🔔 Notifications / 🔵 Other, classified by LLM
- **AI Topic Grouping (Level 2)** — Click a category card and AI groups emails by topic/project
- **Mind-map Tree Lines** — Category cards → topic groups → email list connected with SVG tree lines
- **AI Smart Reply Drafts** — Auto-generate reply drafts in Markdown editor (Cat 1/2)
- **Link to Task** — Every email can be linked to a Task; AI generates title, description, and determines type (task/bug/story)
- **Unlink Task** — Delete linked task with confirmation dialog
- **Batch Dismiss** — Multi-select and dismiss emails at once; 15 per page with pagination
- **Auto-show Original Body** — Cat 1/2 emails display the full email body on open
- **Read Original Toggle** — Button toggles between Show/Hide original email body
- **Unread Indicator** — Orange dot on unopened emails, disappears after viewing
- **Search** — Full-text search across sender, subject, and summary
- **Notification Badge** — Red dot on Email menu when new mail arrives
- **Category Descriptions** — Each category shows an explanation bar below the cards
- **All 4 Categories Saved** — Newsletters and low-priority emails are no longer discarded

### 📝 Report Editor Enhancements
- **AI Action Buttons** — ✨ Polish / 📝 Summarize / 📖 Expand / 🌐 Translate
- **More Report Types** — Monthly, Sprint, and Custom added alongside Daily/Weekly

### 🏠 Welcome Guide (Replaces Setup Wizard)
- **Setup Wizard Removed** — Users land directly in the chat interface with no blocking overlay
- **Interactive Setup Checklist** — LLM API Key, Email, Git, API Keys, Daily Standup — each with a direct Configure button and feature description
- **LLM Soft-Gate Banner** — Prominent warning above chat input when no API key is configured, with "Configure Now" button
- **Language & Theme Selectors** — Switch directly in the welcome screen
- **Completion Message** — Congratulations shown when all required items are configured

### 🎨 UI & Branding
- **New Deep Indigo Default Theme** — Tomatovector brand color `#4338CA`
- **Updated App Icon** — Installer and application icons match the new indigo color scheme

---

## 🔧 Improvements

### Tasks Panel
- **Instant Drag & Drop** — Optimistic UI update; cards move immediately without waiting for API
- **First-Time Drag Hint** — Animated tutorial banner on first visit

### Markdown Editor
- **Text Alignment Fix** — Left/Center/Right alignment now correctly saved to Markdown
- **Empty Table Visibility** — Fixed empty tables collapsing to 0px width (invisible)
- **Toolbar i18n** — All tool button tooltips now properly switch between Chinese/English

### Email System
- **No Auto Issue Creation** — Emails no longer auto-create tasks on arrival; manual linking only
- **AI Draft Save Fix** — Fixed missing `smartEmailId` in generateDraft
- **Dismiss Button Style** — Amber color instead of muted gray (no longer looks disabled)
- **Dismiss Loading State** — Spinner + "Processing..." shown during dismiss
- **Connection Status Fix** — Fixed "Disconnected" showing when IMAP is actually connected
- **Email Menu Position** — Moved to after Home in the bottom menu bar

### Update Check
- **About Page Check** — Manual update check with download progress and install
- **Timeout Fallback** — Auto-shows "Up to date" after 15 seconds if no response
- **State Persistence** — Download progress survives tab switches and restarts
- **Store Build Detection** — Microsoft Store builds automatically disable OTA and show "Update via Store"

### Evening Report
- **Deduplication Fix** — Fixed timer and manual generation creating duplicate reports

### Language
- **English/Chinese Only** — Simplified language options to en/zh

## 🗑️ Removed
- SetupWizard full-screen setup wizard (replaced by Welcome Guide)
- Email functionality from Tasks panel (migrated to dedicated Email panel)
- Cat 1/2 auto Issue creation on email arrival
