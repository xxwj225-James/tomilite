# TomiLite v2.0.2

**Since v2.0.1** — Startup reliability, standup email sections, MCP client UI polish, and multi-session concurrency fixes.

---

## 🔧 Startup Reliability

- **Fixed Startup Error root cause**: `KnowledgeCache.lang` had NULL values from an early migration, making `prisma db push` fail on every launch — schema version stuck, full migration re-run each startup. New migration backfills NULLs so db push succeeds.
- **Migration loop breaker**: schema version is now recorded even when db push fails (best-effort), preventing repeat migrations on every launch.
- **Longer startup window**: API readiness wait extended 45s → 90s to cover slow first-launch migrations.

## 📧 Standup — Email as Separate Section

- **Morning brief**: email-derived tasks no longer mixed into the task table; a dedicated `📧 Pending Emails` section lists unprocessed urgent/action-required emails.
- **Evening report**: today's emails appear in their own section (🔴 urgent / 🟡 action / 🔵 info) in both LLM-generated and local fallback reports.
- **Empty-state logic**: reports now generate when the only activity is email.

## 💬 Multi-Session Chat Fixes

- **Concurrent task 400 fix**: running assistant placeholders (empty content) are filtered from LLM history — fixes "message must not be empty" errors on the second concurrent task (Kimi/DeepSeek).
- **Session-locked saves**: `saveMsg` writes to the session captured at send time (`lockedSid`) — output no longer mixes across sessions when switching mid-stream.
- **SSE error preserved**: real error messages from the server are no longer overwritten by the generic "AI didn't respond" fallback.

## 🔌 MCP Client Polish

- **Add button fixed**: new-server form now opens (was a no-op due to a null-sentinel bug).
- **API key masked display**: editing shows `xxxx****abcd`-style masked key (LLM key pattern) — stored AES-256-GCM encrypted, never returned in plaintext.
- **HITL Mode removed** from the config form — it's a TomiHub server-side concern, not a client setting.
- **Full i18n**: all MCP Servers tab strings in Chinese / Japanese / English.
- **Welcome guide**: MCP Servers setup card added with configure shortcut and completion check.

## 🎨 Task Panel

- **Click vs drag zones**: click # or Title opens the task editor; drag Priority/Type/Created/Due/Updated columns to change status. No more accidental drags on click.
- **Updated hint bar**: explains the new interaction, dismissible.
- **`updatedAt` on status change**: drag-to-status now bumps the Updated column.
