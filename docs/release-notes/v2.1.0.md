# TomiLite v2.1.0

**Since v2.0.9** — Hosted free trial (no API key needed), a voice on a future Pro plan, and a fix for the very first message.

## ✨ Features

- **🌐 Hosted free trial** — a new "Hosted" segment in **Settings → LLM**. Sign in with your email (one-time code sent to your inbox) and start chatting right away — no API key, no card. A live panel shows your remaining trial credit, and every capability (chat, email, standup, knowledge, health, search, learn, system) runs through the official gateway, so you don't have to configure a single provider locally. Switching back to your own API key is one click.
- **🗳️ Subscription-intent survey** — inside the hosted trial you'll find a single question asking whether you'd subscribe if a paid plan launches. One vote per account, changeable anytime — a lightweight signal to help decide what comes next.
- **📡 First-run telemetry consent** — a one-time, opt-in dialog explains exactly what anonymous usage data would be collected (and what never leaves your machine). Decline is respected and remembered; you can flip the switch later in **Settings → About**.
- **🎨 Brand refresh** — updated app icon and splash.

## 🐛 Fixes

- **First message no longer disappears on a fresh install** — an empty-session launch now activates the session before you type, so your opening message gets a real reply instead of being silently dropped.
- **Gateway paused UX** — when the hosted service is temporarily closed, chat shows a clear localized notice and errors are human-readable (account disabled, quota exhausted, model not allowed) instead of failing with a bare HTTP code. Expired sessions clean themselves up and ask you to sign in again.
