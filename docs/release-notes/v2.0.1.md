# TomiLite v2.0.1

**Since v1.6.0** — Rebrand, multi-session chat concurrency, MCP client, task panel redesign, and cross-session output isolation.

---

## 🆕 Multi-Session Chat with Concurrency

- **Tomihub-style session isolation**: each session has its own message store — switching sessions mid-stream keeps the running task in its original session
- **Concurrent task gate**: max 3 simultaneous running tasks across all sessions (browser connection limit)
- **Per-message abort controller**: stop button aborts the correct running task in the current session — no more cross-session interference
- **Session-locked output**: streaming messages and DB saves are locked to the session that initiated the request; switching sessions mid-stream does not mix output
- **Empty running placeholder filter**: history sent to LLM excludes running assistant messages (prevents API 400 errors on concurrent tasks)

## 🌐 MCP Client (Phase 1–3)

- **Multi-server connection management**: add, test, enable/disable MCP servers via Settings → MCP Servers
- **Auto-negotiating protocol client**: detects TomiHub-style, JSON-RPC, and legacy `/tools/call` servers
- **Dynamic tool injection**: discovered tools are injected as `mcp__<server>__<tool>` functions directly into the AI agent's tool list — capped at 25 per request
- **30s TTL tool cache**: per-server discovery with lazy refresh, offline servers gracefully excluded
- **Security**: API keys encrypted at rest via AES-256-GCM, tokens never reach the LLM, HTTPS enforced for remote servers
- **Management API**: CRUD + test/connect/disconnect/refresh endpoints
- **`McpServer` model activated**: schema extended with transport, headers, status, toolsJson, hitlMode columns (SCHEMA_VERSION 20)
- **`isMcpPath` security fix**: narrowed prefix from `/api/mcp` to `/api/mcp.` to prevent `/api/mcpServers.*` bypassing token auth

## 🎨 Task Panel

- **Click vs drag**: click opens task editor (detail view); drag (≥5px movement) changes status — both work on the same row
- **Tab-based workflow**: TODO / In Progress / Done tabs with color-coded badges
- **Resizable columns**: drag column borders to adjust width
- **8 sortable columns**: # / Title / Priority / Type / Created / Due / Updated with DB-persisted preferences

## 🛠 Fixes

- **Note editor paste**: inline `<span style="...">` from Claude Code, VS Code, and web pages are stripped before insertion — prevents raw HTML tags in saved markdown
- **Standup error logging**: save failures no longer swallowed silently; backend catches and returns error details
- **Chat history empty**: `switchSession` now correctly calls `chatHook.switchSession()` to update active session ID
- **Shared `abortRef` removed**: each message carries its own `AbortController`, eliminating cross-session abort interference
