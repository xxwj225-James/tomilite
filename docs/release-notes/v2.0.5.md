# TomiLite v2.0.5

**Since v2.0.4** — Agent behavior improvements, PPT attachments, and richer onboarding.

---

## 🤖 Agent Behavior

- **App-context system prompt**: Tomi now understands TomiLite as a chat-first workspace — reviews, feedback requests, and analysis discussions are answered directly in chat. Tools are called only when the user wants a workspace action (create/update/save).
- **create_report tightened**: reports are only created when the user explicitly asks to generate one — "review this document" no longer produces a report
- **Guard routing rewritten**: conversation turns are no longer nudged toward tool calls

## 📎 Attachments

- **PowerPoint (.pptx) support**: attach a PPT deck and Tomi reads the text of every slide (up to 20 slides) for review, summary, or Q&A

## ✨ Onboarding

- Welcome-guide suggestion chips now cover update-task and email-summary examples (en/zh/ja)
- README gained a "What can Tomi do?" example table — chat-to-action examples visible before installing

## 🔒 Security

- electron 33 → 43, electron-builder 25 → 26, xlsx → 0.20.3 (SheetJS CDN), mailparser 3.7 → 3.9 — 35 of 39 Dependabot advisories fixed (the remaining deepmerge-ts chain awaits an upstream fix)
