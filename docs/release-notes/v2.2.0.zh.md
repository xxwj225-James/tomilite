# TomiLite v2.2.0

**自 v2.1.3 起** —— 补上 Agent 此前根本做不到的两件事：打开链接、读你的会议。过去贴一个网址是读不了的，所以「这个页面说了什么」会把整轮的回合耗在瞎猜上；会议数据对所有工具都不可见，所以关于决议和行动项的问题无解。现在两者都有工具了 —— 而且真的用尽回合时，它会说明原因，不再打印 `(no response)`。

## ✨ 新功能

- **🔗 Tomi 能打开链接了** —— 新增 `fetch_url` 工具。在此之前根本没有通往网页的路径：`web_search` 只查搜索引擎、返回标题和摘要，从不抓取结果页；`curl` 和 `wget` 被 shell 工具的白名单挡死；默认也没有配置任何 GitHub MCP server。于是你贴一个仓库链接问它，Agent 会把十个回合全花在 Windows 上根本不可能成功的 `ls`、`grep` 变体上，最后一句话都答不出来。
  - **GitHub 链接会被改写到真正能返回内容的端点。** github.com 的仓库页、`blob` 页、`tree` 页都是客户端渲染：原样抓下来，一个仓库页就是约 15 KB 的 GitHub 自身导航，里面没有 README。现在仓库链接解析到它的 README，`blob` 链接取原始文件，`tree` 链接给出可读的目录列表。抓到的 README 里的相对链接会被改写成绝对地址，所以那个真正能回答问题的链接，下一次调用就点得下去，而不会变成 `https://docs/meetings.md`。
  - **它是带护栏的。** 只允许 http 与 https、一次调用一个网址、整条重定向链共用**一个** 15 秒截止时间、下载量和交给模型的文本量各有上限，并且**每一跳**都检查是否私有/本地地址，而不只是第一跳。最后这条在这里尤其重要：本 API 对 localhost 豁免令牌校验，所以一个让模型去抓 `http://127.0.0.1:3192/api/...` 的页面，否则就能打到应用自己的 API 上。
  - **抓回来的内容是数据，不是指令。** 页面返回的任何东西都不会被自动执行，工具描述里也明说了这一点。
- **🗂 Tomi 能读你的会议了** —— 两个只读工具：`list_meetings` 与 `get_meeting`。会议数据存在应用数据库里，而 `shell_exec` 和 `search_local_data` 都看不到它，所以「关于 X 我们当时决定的是什么」此前只能靠翻源码来回答。`list_meetings` 可按状态、标题片段、是否归档过滤；`get_meeting` 返回某场会议的摘要、决议、行动项与纪要，转写全文只在明确要求时才带 —— 它是最贵的字段，所以是选配。
- **沙箱现在是被告知的，而不是靠试出来的。** 系统提示词里写清了 `shell_exec` 接受哪些命令，以及两条以前只能靠失败才能学到的后果：`ls`、`cat`、`grep`、`find`、`type` 是 Unix 命令，在 Windows 上不存在；`curl`/`wget` 一律拒绝。同时告诉它：缺哪个仓库根目录就直说，不要在命令变体上浪费回合。

## 🐛 修复

- **用尽回合的一轮现在会说明原因。** Agent 撞到 10 回合上限时，聊天里会被写进字面量 `(no response)` —— 没有任何解释，也分不清是模型坏了还是回复为空。现在两种情况都会给出本地化的原因：达到回合上限，或模型没有返回内容。
  - 结束超限回合的那个「强制总结」调用本身还在提供完整工具表，于是被要求「总结你查到的东西」的模型可以再回一个工具调用 —— 而调用方只读 `content`，会把它丢掉，留下空回复。这正是当初产生空白轮的机制。现在总结调用不再提供任何工具。
  - `finish_reason` 与 token 上限现在会记入日志，因此「被截断的回答」和「沉默的回答」可以区分开。
- **会议音频保留策略现在真的执行了。** `retentionDays` 此前只是被存下来、在界面上显示，从未被落实 —— 音频永远留在磁盘上。现在每小时清扫一次，删除超过保留期的会议音频，而且只删音频：转写、摘要、纪要、决议、行动项都保留。仍在录音或转写中的会被跳过，`retentionDays: 0` 依然表示永久保留，删除动作会被打戳，不会重复尝试。
- **新录音现在遵循 Settings 里的默认值。** `meeting.create` 此前写死了自己的 `lang: 'auto'` 和自己的保留期默认值，导致你在 Settings 里选的语言和保留期，对每一个从界面发起的录音都不起作用。现在由服务端默认值决定，入口不再覆盖它。
- **会议时长按秒上报。** 时长此前被四舍五入到整分钟，所以任何短于 30 秒的会议都显示成 `0`，看起来像数据缺失。现在同时返回秒和分钟（一位小数）。
- **会议估算器的托管模型标志读的是一个 API 根本不返回的字段**，所以那个分支永远不可能为真。现在改读 API 实际发送的字段。

## ⚠️ 说明

- **无 schema 变更。** 本次发布不会迁移你的数据库。
- **安装包体积不变** —— 185.8 MiB，比 v2.1.3 大约 6 KB。没有新增原生依赖。
- **`fetch_url` 有一个已知缺口。** 通过 DNS 解析到私有地址的主机名仍会被抓取，因为 HTTP 客户端在校验之后会重新解析该名字。要堵住它需要把解析结果钉住，目前没有做。字面量的私有地址、`localhost` 以及内网域名都会被拒绝，重定向目标同样如此。
- **`fetch_url` 会访问公网。** 它是唯一一个会去抓「你或模型指定的页面」的工具。它不发送任何凭据，也不会执行它读到的东西。
