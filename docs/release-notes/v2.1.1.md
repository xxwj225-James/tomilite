# TomiLite v2.1.1

**Since v2.1.0** — quick fix for note deletion.

## 🐛 Fixes

- **Note deletion no longer hangs on "Deleting…"** — deleting a note now always releases the UI. Previously the busy flag never reset after a delete (success or failure), so the button stayed stuck on "Deleting…" and every other note looked like it was still mid-delete until the app was reloaded. The flag is now reset in both paths.
