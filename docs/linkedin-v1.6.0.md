I built an AI productivity tool for developers — and it started with a simple frustration.

Context-switching between email, tasks, notes, and daily reports was eating hours of my day. I wanted one assistant that reads my inbox, organizes my work, writes my standups, and remembers everything — without shipping my data to someone else's cloud.

So I built **TomiLite** 

🔗 https://tomatovector.com/

---

**What it does:**

📧 **Intelligent Email Triage** — 4-category AI classification (Urgent / Action Required / Notifications / Low Priority) with LLM sub-grouping and auto-generated reply drafts. Reply directly, link emails to tasks, or batch dismiss.

📋 **Daily Reports** — Morning brief with priority-sorted tasks. Evening report with completed items, code activity, and tomorrow's suggestions. One-click export to Excel, Word, or HTML.

✅ **Tasks, Notes & Reports** — Kanban board, Markdown editor, multi-note export, pagination. Everything in one place.

📊 **Health Score Dashboard** — 4-dimension productivity metrics with 7-day trend sparkline. Know if you're on track at a glance.

💬 **Chat-First Everything** — Create tasks, write notes, generate reports, draft email replies — all by typing. No forms, no menus. Just tell the AI what you need and it happens. Kanban syncs, editors update, reports land in your inbox.

🔌 **MCP / Claude Code Integration** — TomiLite connects to Claude Code via MCP (Model Context Protocol). AI can call tools, you approve or deny in real-time with a single click. Long-polling, synchronous feedback, hallucination guard built in.

🤖 **Multi-LLM** — DeepSeek, Qwen, Kimi. Your data stays local, your API key is encrypted. No cloud dependency.

🌐 **Full i18n** — Chinese, Japanese, English. Every label, every report, every AI response.
